# Style Up: techwear store-finder landing page

**One line:** a dark, HUD-framed landing page where the visitor's cursor paints a second outfit onto the hero photo, then walks them through the garments and into a store finder.

The first screen is a full-bleed sunset photo of a masked figure on a hill in everyday clothes. Moving the cursor (or a finger) paints a soft, glitch-edged trail through which the same figure appears in full techwear, with cyan-tinted scanlines inside the revealed area; a scripted sweep shows first-time visitors the trick, and a "Suit up" button swaps the whole photo. Below the hero the page changes register from terminal to garment: a scroll-lit manifesto, three close-up "anatomy" photos with numbered pins, and a store finder with search, city chips, "use my location" and a compass that plots stores by bearing and log distance. It ends with an email signup whose headline names your nearest store once you've shared your location.

## How to use

1. **Add your media** to the five slots in Part A (exact paths, any listed format).
2. **Paste Part B** into a coding agent opened in that folder. It builds the site, converts your media and reads its sizes into one config file.
3. **Swapped media later?** Run `bash scripts/build-media.sh` again, then ask the agent to re-check pins, focal points and alt texts in `src/config.js`.

### 4. Media pipeline

Write `scripts/build-media.sh` (bash; runs in Git Bash on Windows) that uses `ffmpeg` (libwebp) and `ffprobe`, so the buyer can re-run it. For each slot it writes a full-size WebP and a small WebP into `public/media/`, then prints every output's width × height and file size:

```
mkdir -p public/media
src() { ls assets/$1.* | head -n1; }
for s in hero-base hero-reveal; do
  ffmpeg -y -i "$(src $s)" -vf "scale='min(1920,iw)':-2" -c:v libwebp -quality 80 public/media/$s.webp
  ffmpeg -y -i "$(src $s)" -vf "scale=960:-2"            -c:v libwebp -quality 78 public/media/$s-960.webp
done
for s in detail-1 detail-2 detail-3; do
  ffmpeg -y -i "$(src $s)" -vf "scale='min(1920,iw)':-2" -c:v libwebp -quality 80 public/media/$s.webp
  ffmpeg -y -i "$(src $s)" -vf "scale=900:-2"            -c:v libwebp -quality 78 public/media/$s-900.webp
done
for f in public/media/*.webp; do
  printf '%s ' "$f"; ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of csv=p=0:s=x "$f"; du -k "$f"
done
```

- Hero images: full set = source width capped at 1920 px; small set = 960 px wide. Detail images: full = capped at 1920 px; small = 900 px wide.
- **Size budgets:** each full-size file ≤ 200 KB, each small file ≤ 80 KB. If a file is over budget, lower `-quality` in steps of 5 (not below 65) for that file only.
- Copy the printed widths and heights into `CONFIG`. The full-size width is also the `w` descriptor in each `srcset`.
- **Focal points** (you set these by looking at the images, then store them in `CONFIG`): `hero.figureX` = the horizontal centre of the person in hero-base, as a fraction of image width (0–1); `hero.figureTop` = roughly the top of their head as a fraction of image height minus 0.05 (demo: 0.2); `drops.position` = the object-position for the dimmed signup background (demo: 60% 40%, keep it unless the subject falls out of frame).

### 8. Behaviour

#### 8.1 Modes

- **Reduced motion** = `matchMedia('(prefers-reduced-motion: reduce)')` read once on mount. When true: no GSAP scroll animations at all (content is fully visible), no DecryptedText scramble, no ScrollReveal dimming, marquees stand still, no scripted hero sweep, the full-swap toggle is instant, CSS animations on the badge and dot are off, compass needle has no transition, `scroll-behavior: auto`. The cursor trail still works.
- **Touch:** pointer events of type `touch` are ignored by the hero; touch events drive it instead (see 8.2). Hover-only styles are inside `(hover: hover)`.
- **No JS:** all content is in the markup and visible (GSAP only animates *from* hidden states).

#### 8.2 Signature: cursor-trail reveal (`RevealCanvas`)

The base photo is a normal `<img>` for a fast first paint. The reveal photo is drawn on the canvas and only shows through a mask painted from the pointer trail. Brush stamps age out, so the trail closes behind the cursor.

- **Loading:** create an `Image` with async decoding; source = small reveal file if `window.innerWidth < 900`, else full. On load, run resize.
- **Resize** (ResizeObserver on the wrapper, plus image load): W, H = wrapper size; `dpr = min(devicePixelRatio || 1, 2)`; canvas pixel size = round(W·dpr) × round(H·dpr); an offscreen **mask canvas at half resolution**, round(W/2) × round(H/2). Compute the cover rect: `s = max(W/iw, H/ih)`, `w = iw·s`, `h = ih·s`, `x = (W − w)·px`, `y = (H − h)·py`, with (px, py) = `CONFIG.hero.position`, or `CONFIG.hero.mobilePosition` when the viewport is ≤ 860 px wide. Then request a frame.
- **Constants:** stamp life `LIFE = 2200` ms; glitch block life `BLOCK_LIFE = 700` ms; brush radius `R = max(46, min(W, H) × 0.075)`.
- **Organic stroke:** keep a running `travel` distance, initialised to a random 0–1000. `wave(d) = 0.78 + 0.22·sin(0.011d) + 0.14·sin(0.037d + 1.3)`; `drift(d) = 0.22·sin(0.017d + 0.6) + 0.1·sin(0.051d)`.
- **Adding a point (x, y):**
  - If there is a previous point: `d` = distance to it, step = 0.26R, `n = min(40, floor(d / step))`. If n = 0, return without updating the previous point (small moves accumulate). Unit normal = (−dy/d, dx/d). For i = 1…n: `travel += d/n`, then stamp at the i/n interpolated point. A stamp has radius `R·wave(travel)` and is pushed sideways along the normal by `drift(travel)·R`. With probability 0.07 also add a satellite blot on a random side (±1) at distance `R·(0.9 + rand·0.5)` along the normal, radius `R·(0.22 + rand·0.22)`.
  - If there is no previous point: one stamp at (x, y), radius 0.9R.
  - Then, with probability 0.3, add a hard-edged glitch block: random angle a, distance `R·(0.75 + rand·0.6)`, size s = `4 + rand·10`, width `s·(1 + rand·2.5)`, height `0.5s`, top-left corner at (x + cos a·dist, y + sin a·dist).
  - Store the point as previous; on the very first point ever, fire `onFirstReveal` (quiets the badge). Request a frame.
- **Each frame** (rAF, only while needed):
  1. Drop stamps older than LIFE and blocks older than BLOCK_LIFE. Ease the full-swap amount: `full += (fullTarget − full) × (reduced ? 1 : 0.08)`; snap when within 0.002.
  2. Clear the canvas. If the image isn't loaded, stop.
  3. **Mask** (scaled 0.5): clear; for each stamp, age `k = (now − t)/LIFE`, `grow = 0.75 + 0.35·sin(min(1, 2k)·π/2)`, radius `r = s.r·grow·(1 − 0.6k²)`, alpha `a = 1 − k²`; fill a square of side 2r with a radial gradient: white at alpha a at 0, alpha 0.9a at 0.55, transparent at 1. For each block, age k: fill white at alpha 1 if k < 0.5 else 0 (hard on/off, like a dropped packet). If full > 0, fill the whole mask white at alpha `full`.
  4. **Composite** (transform scaled by dpr): draw the reveal photo at the cover rect; switch to `destination-in` and draw the mask stretched to W × H; switch to `source-atop` and fill everything with `rgba(0, 240, 255, 0.05)` (cyan tint), then draw scanlines: 1 px tall rows of `rgba(0, 0, 0, 0.16)` every 4 px, starting at y = `(now / 40) mod 4` (they crawl down). Restore `source-over`.
  5. Request another frame while stamps or blocks exist or full ≠ fullTarget.
- **Input:** `pointermove` on the wrapper (ignore `pointerType === 'touch'`) adds the local point; `pointerleave` clears the previous point. `touchstart` and `touchmove` (passive) add the first touch's local point; `touchend` clears the previous point. Any real input cancels a running demo sweep.
- **Scripted demo sweep:** 1400 ms after the hero mounts, unless reduced motion (and only if the image is loaded). Duration 2600 ms. For progress k ∈ [0, 1], eased `e = 1 − (1 − k)²`, the point in image-normalised coordinates is `x = figureX + sin(e·π·sweepWaves)·sweepAmp`, `y = figureTop + e·sweepSpan` (demo: 0.48 + sin(3πe)·0.09, 0.2 + 0.72e), mapped through the cover rect (rect.x + x·rect.w, rect.y + y·rect.h), and fed to "add a point" every animation frame. Clear the previous point before and after.
- **Full swap (Suit up / Take it off):** sets fullTarget to 1 or 0 and requests a frame; updates the HUD layer label and the button's text and `aria-pressed`.
- Clean up every listener, observer and rAF on unmount.

#### 8.3 Decrypting headline (`DecryptedText`)

Renders an sr-only span with the real text plus an `aria-hidden` span with the animated text (initially the real text). Glyph set: `ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789/<>#%&*+=_`. On mount (skipped under reduced motion), starting at `performance.now() + delay`, each frame the number of locked characters is `max(0, floor(elapsed / 28))`; characters with index < locked, spaces, periods and apostrophes show the real character, all others a random glyph. Stops when all characters are locked (left to right, 28 ms per character).

#### 8.7 Store finder logic and compass (`Stores`, `Radar`)

- **State:** origin (default first city, Bucharest), query, active store id, geo status (idle | locating | denied). The list = stores whose name, city, country or any tag contains the trimmed, lowercased query (all when empty), each with its distance from origin, sorted nearest first. Active = the hovered/clicked store, else the first in the list.
- **Chip click:** set origin to that city, clear active and the query.
- **Use my location:** if geolocation is unavailable, set denied. Otherwise set locating and request position with `timeout: 8000`, `maximumAge: 600000`. On success: origin = `{ id: 'me', label: 'You', lat, lng }` (no chip is pressed), clear active and query, back to idle, and pass the nearest store (over **all** stores, ignoring the query) up to the page so the Drops headline names it.
